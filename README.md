# ml-language-app



Spaced repetition language learner with a learned recall model, built in Python



\## status :



Early development 



\## Motivation 





I started this project after learning Mauritian Creole. Because few language apps support it, I had to combine several tools, including Duolingo and ChatGPT, and none of them was designed for the language. I wanted to build an app that treats less commonly taught languages as first-class. Machine learning is a natural fit, because a model of how a learner forgets works regardless of how much data exists for the language itself, and it is also a chance to explore a field I am keen to work in.
